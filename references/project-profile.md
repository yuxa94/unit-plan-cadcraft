# 사용자 로컬 참조 프로파일

실제 DWG, XREF, 추출 부품, 원본 형상/handle 덤프와 화면은 공개 저장소 밖의 작업 폴더에 보관합니다. 프로젝트 도면은 이 공개판에 포함되지 않습니다.

1. 사용자가 지정한 기준 DWG의 전체 경로, 저장 상태와 해시를 기록합니다. 평면 표현과 중심선 자료의 우선순위를 명시합니다.
2. XREF 상대 폴더 관계를 유지하고 읽기 전용 분석을 합니다. 미저장 변경과 디스크 저장본을 구분합니다.
3. 대표 영역의 벽 구성·마감·단열·해치·문창·문자·치수를 중첩 블록 내부까지 읽습니다. 원본 객체와 변환 근거를 로컬 profile에 기록합니다.
4. 필요한 부품을 로컬 파일로 분리하고 기준점·실제 프레임폭·내외부 방향·출처를 측정합니다. 전체 bbox를 프레임이나 제품 규격으로 간주하지 않습니다.
5. 관찰값, 사용자 확정, 제안, 미확정을 분리합니다. 부품은 새 프로젝트 적용 검토 후 사용합니다.
6. 대표 평면을 별도 DWG에 재구성하고 [벤치마크](benchmark.md)로 범위를 검증합니다.

예시 작업 구조:

```text
my-local-project/
  references/source/       # DWG와 상대 XREF
  profile/                 # 관찰값, 실제 부품, 기준점, 출처
  jobs/unit-001/
    input/
    decisions.json
    operations/
    outputs/
    review.json
```

이 정보는 로컬 자료입니다. 코드 저장소에 자동으로 포함하지 마세요.

## CADCraft에서 참조 도면 읽기

- CADCraft는 DWG를 acadrust 변환기로 엽니다. `open` 결과의 `warnings`(읽지 못한 객체)를 profile에 기록하고, 가능하면 원본 CAD에서 DXF로 저장한 사본도 받아 대조합니다.
- 동적 블록, SHX 글꼴, CADCraft가 모델링하지 않는 객체는 형태가 다르게 보이거나 빠질 수 있습니다. 화면만 보고 원본에 없다고 판단하지 않습니다.
- 참조 도면은 읽기 전용입니다. 분석 중 `save`를 호출하지 않습니다.
